# ApplyRN

I'm testing to see if being fast lands me a j o b .

ApplyRN watches company job boards (Greenhouse, Ashby, Lever) and pings you on Telegram within a couple minutes of a new role going up. It's a personal radar for internships and early-career jobs: you see it first, you apply first.

## Stack

TypeScript · Cloudflare Workers · D1 · React + Vite dashboard · Telegram Bot API
